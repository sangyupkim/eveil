# 잿빛 연대기 — 방향과 로드맵

> 2026-11-11 작성. 지금 판: Flare 2D 쿼터뷰 · 지역 8곳 · 몬스터 49종 · 스킬 25종 · 장비 75종 · 퀘스트 32개 · 마을 건물 4종(대장간 강화 · 광산 · 약초밭 · 여관 용병).

## 1. 한 줄 정체성

**"싸운 방식이 캐릭터를 만들고, 비운 시간에는 마을이 자란다."**
레벨 대신 행동 비율로 스탯이 오르는 *각성*과, 꺼 둔 동안에도 돌아가는 *마을 · 용병*의 두 바퀴로 굴러가는 방치형 액션 RPG.

## 2. 지금 재미의 뼈대 (플레이 소감 기준)

| 잘 되는 것 | 약한 것 |
|---|---|
| 몹을 잡는 손맛 (타격 · 숫자 · 효과음) | 잡은 뒤 *무엇을 위해* 잡는지가 흐리다 |
| 스킬북을 주워 배우는 설렘 | 장비가 숫자만 바뀌고 "득템" 순간이 약하다 |
| 행동대로 스탯이 오르는 각성 | 각성이 화면에서 잘 체감되지 않는다 |
| 마을 건물 · 용병 (막 생김) | 마을과 사냥이 서로를 끌어당기지 못한다 |

## 3. 핵심 순환 (목표)

```
사냥 ──► 전리품(장비 · 강화석 · 재료 · 금화)
  ▲              │
  │              ▼
캐릭터가 강해짐 ◄── 마을(강화 · 제작 · 연구)
  ▲              │
  │              ▼
던전 · 보스  ◄── 용병(방치 사냥) ── 꺼 둔 시간
```

- **사냥**은 *재료*를 준다 → 마을이 재료로 캐릭터를 키운다 → 더 깊은 지역 · 던전을 연다 → 더 좋은 재료.
- **방치**는 *보조 바퀴*다: 용병 · 생산은 사냥을 대신하지 않고, 사냥이 더 빨리 굴러가게 돕는다 (강화석 · 물약 · 낮은 등급 장비).

## 4. 단계별 로드맵

### 1단계 — 순환 닫기 (다음 작업, 1~2회 분량)
1. **재료 드롭**: 지역마다 고유 재료 1종(개미 껍질 · 뼛가루 · 서리 결정 …) — 몹이 떨어뜨리고, 마을 건물 단계 올리기에 *금화 + 재료*가 들게.
2. **제작소(새 건물)**: 재료로 *지역 세트 장비*(2 · 4부위 세트 효과)를 만든다 → "이 지역 몹을 잡을 이유".
3. **강화 연출**: 강화 단계가 겉모습에 보이게 (+5 무기 은은한 빛, +8 이상 강한 빛 · 이름 색).
4. **각성 체감**: 각성 때 고른 스탯이 실제로 무엇을 바꿨는지 한 줄로 (예: "힘 +3 → 검 피해 +9%").

### 2단계 — 던전 (2~3회 분량)
1. **던전 입구**를 지역마다 하나 (Flare 동굴 · 던전 타일 사용). 들어가면 별도 맵: 방 3~5개 → 마지막 방 우두머리.
2. **열쇠**: 지역 네임드 · 보스가 던전 열쇠를 떨어뜨림 → 필드 사냥과 던전이 이어진다.
3. **던전 전용 보상**: 영웅 · 전설 확정 상자, 스킬북 상급, 세트 재료.
4. **층 · 난이도**: 같은 던전을 단계(1~10)로 반복, 단계마다 몹 강화 · 보상 증가 → 장기 목표.

### 3단계 — 마을 깊게 (2회 분량)
1. **연구소**: 금화 + 시간으로 영구 능력(물약 회복량 · 용병 속도 · 드롭률) — 긴 방치 목표.
2. **용병 성장**: 용병에게 내 남는 장비를 입혀 성과 상승 → "쓸모없던 장비"에 쓰임.
3. **마을 꾸미기**: 빈터 확장(4 → 8), 건물 단계가 겉모습에 반영.
4. **알림**: 생산 가득 · 용병 귀환을 접속할 때 한 화면으로 정리.

### 4단계 — 장기 목표 (이후)
- 시즌 · 주간 과제(정해진 몹 · 던전 단계), 업적 · 칭호, 서버 순위(던전 최고 단계).
- 지역 9~12 (Flare 동굴 · 설원 · 던전 확장), 몬스터 그림 교체(별도 작업으로 한 번에).

## 5. 스스로 분석 — 이 로드맵의 약점과 고칠 방향

| 약점 | 왜 문제인가 | 고칠 방향 |
|---|---|---|
| **방치가 사냥을 대신할 위험** | 용병 보상이 크면 사냥할 이유가 사라진다 | 용병은 *강화석 · 물약 · 하위 장비* 위주, 세트 재료 · 상급 스킬북은 직접 사냥 · 던전에서만 |
| **강화 인플레** | +10이 쉬우면 지역 난이도가 무너진다 | 강화 상한을 대장간 단계로 묶음(이미 적용), 상위 단계는 던전 재료 필요 |
| **재료 종류가 많아 가방이 넘침** | 40칸 가방이 금방 찬다 | 재료는 가방이 아닌 *마을 창고*로 바로 (강화석처럼 숫자로만) |
| **던전이 필드와 따로 놀 위험** | 던전만 돌게 된다 | 열쇠를 필드 네임드 · 보스가 주게 해서 두 곳을 오가게 |
| **휴대폰 부담** | 맵 · 그림이 커질수록 렉 | 던전은 작은 별도 맵, 몬스터 그림은 줄여 담기(이미 적용) 유지 |
| **각성 시스템이 숨는다** | 레벨이 없어 성장 체감이 약하다 | 각성 연출 · 스탯 변화 한 줄 · 능력 창에 "다음 각성까지" 크게 |
| **목표가 흐린 순간** | 퀘스트 32개가 끝나면 할 일이 없다 | 던전 단계 · 연구 · 세트 수집을 "다음 목표" 줄에 자동으로 띄움 |

## 6. 우선순위 결론

1. **재료 드롭 + 제작소(세트 장비)** — 사냥에 이유를 준다. 가장 효과가 크고 작업은 작다.
2. **던전 1개(들판)** — 구조를 만들고 나머지 지역에 복제.
3. **강화 · 각성 연출** — 성장 체감.
4. **연구소 · 용병 장비** — 방치 깊이.

> 원칙: *직접 사냥이 늘 가장 좋은 보상*이고, 방치는 그 사냥을 빨리 굴리는 보조. 휴대폰에서 끊기지 않는 것이 새 기능보다 먼저.
