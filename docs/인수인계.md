# 인수인계 — 잿빛 연대기 (nec_rog)

## 한 줄 요약
어두운 판타지 쿼터뷰 웹 RPG. 레벨 없이 행동 비율대로 스탯이 오르는 "각성", 스킬북 드랍으로 배우고 쓸수록 오르는 스킬, 드랍 장비, 자동 사냥. three.js 3D + KayKit CC0 모델. 빌드 없는 정적 사이트.

## 실행 · 점검
- `npm install` (개발 도구만) → `npm start` → http://localhost:5173
- `npm test` — 각성 · 스킬 · 드랍 · 사망 · 장착 로직 테스트 10개 (통과 상태)
- 에셋 다시 만들기: KayKit 팩 5개를 clone 후 `node tools/prep-assets.mjs <폴더>` (애니메이션은 `assets/models/anims.glb` 하나로 공유)
- 화면 확인은 Playwright(헤드리스 크롬, `--use-angle=swiftshader`). 헤드리스는 느려서 게임 시간이 늦게 흐르므로, 밸런스 확인은 `window.__game.world.update(0.05)`를 반복 호출해 빨리 감기.

## 확정된 기획 (docs/GDD.md v0.2)
싱글 플레이 · PC + 모바일 가로 · 무료 3D(KayKit, 모델은 지금 형태로 확정) · 직업 없음 · 스탯 5종(힘/민첩/지능/정신/체력) · 자동 사냥 있음(EXP·AP·숙련·드랍 80%) · 사망 시 35% 확률로 아이템 1개를 그 자리에 떨굼(15분 보존).

## 진행 중이던 작업 (미완성 · 미배포)
사용자 요청: ① 「sangyupkim/eonrift(영겁의 틈새)」의 UI를 참고해 이 게임 UI를 바꾸기 ② 무료 소리/BGM 적용.

외부 음원 사이트는 이 환경에서 막혀 있어(깃허브·npm만 됨) **소리는 Web Audio로 직접 합성**하기로 함 → 라이선스 문제 없음.

완료:
- `index.html` · `styles.css` 새 레이아웃 (황동 테두리·남보라 판, 초상화+각성 알약, HP/MP/EXP 바, 지역/골드 알약, 접히는 기록 상자, 접히는 우상단 아이콘 메뉴, 둥근 행동 단추, 모바일은 스킬이 공격 단추 둘레 호 배치, 전체 화면 창 `.screen` + `.fs-head` 탭 + 톱니 닫기 단추)
- `src/engine/audio.js` — 지역별 생성형 배경음(town/field/forest/grave/ruins/boss/title) + 효과음 30여 종
- `src/world/world.js` — 효과음 호출 · 지역/보스 근접 시 음악 전환 연결 완료
- `src/ui/hud.js` — 새 마크업에 맞춤(초상화, 메뉴 접기, 스킬 이름/원형 쿨타임, 물약 수)
- `src/ui/icons.js` — 아이템/초상화/메뉴 아이콘을 3D 모델로 렌더

남은 일 (이 순서로):
1. **`src/ui/windows.js` 새 UI로 다시 쓰기** — 덮어쓰기 직전에 중단됨. 지금 파일은 예전 마크업(`.panel`, `h2`)을 가정해서 새 index.html과 맞지 않음. 새 구조: `#window.screen > .fs-head(h2, .tabs, .close) + .body`, 내용은 `.cols > .frame` 두 칸, 아이템 칸은 `.cell` + `itemIcon()` 이미지 + 등급 클래스 `r-magic/r-rare/r-hero/r-legend`, 메뉴 창은 왼쪽 설정(계속하기 금색 plate·배경음/효과음 슬라이더·그림자·자동물약·자동구매) + 오른쪽 `.cards` 바로가기.
2. `src/main.js`: 첫 pointerdown/keydown에서 `audio.unlock()`, 저장값 `st.settings.music/sfx`(기본 0.6/0.8)로 `audio.setVolumes`, 타이틀에서 `audio.setMusic('title')`, 타이틀 외형 선택 버튼에 `portrait(look)` 이미지, 새 버튼(`.plate`) 반영. `player.js` 기본 settings에 music·sfx 추가.
3. `input.js`: `[data-win]` 단추 그대로 동작 확인, 메뉴 키(Esc가 창 없을 때 메뉴 열기).
4. Playwright로 PC(1280×720)·모바일(Pixel 7 landscape) 스크린샷 확인 → `npm test` → 커밋 → **배포**.

## 알아둘 것
- 헤드리스 렌더 확인 시 `[hidden]{display:none!important}` 없으면 창이 겹침 (이미 들어가 있음).
- 마을 울타리는 동서남북 문으로만 드나듦 (`world.waypoint`). 장애물 끼임은 `stuckT`/우회로로 처리.
- KayKit 원본 `prune()`이 애니메이션 샘플러를 못 지움 → prep 스크립트의 `killAnim`/`dropOrphans` 필요.
- eonrift 배경음(sound/*.mp3)은 CC BY 4.0이지만 몽환적 신스라 분위기 안 맞아 안 씀.
