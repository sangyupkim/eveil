# 전투 개편 방향 (확정안, v0.44.36 이후)

## 1. 스킬 피해 계산

스킬 피해 = 공격력 × 스킬 계수 × 스킬 스탯 배율 × 장비 보정(피해 % 등)

- 공격력: 물리 스킬 · 평타 = 모든 장비의 물리 공격력 합, 마법 스킬 = 마법 공격력 합, 혼합 스킬 = 둘 다.
- 스탯 배율: 스킬 자기 스탯 (무기 종류와 상관없음). 혼합 스킬 = 높은 쪽 70% + 낮은 쪽 30%.
- 체력 스킬: 체력 1당 1.5%, HP 보너스는 전체 최대 HP 기준 (v0.44.36 적용됨).
- 정신 스킬: MP 보너스를 전체 최대 MP 기준으로 (정신을 올리면 줄던 것).
- 스킬을 쓰면 그 스킬 스탯이 오른다 (지금도 됨) → 쓰는 스킬 = 크는 스탯 = 세지는 스킬.

## 2. 물리 · 마법 공격력과 장비

- 검 · 둔기 · 활 · 단검: 물리 공격력. 기존 무기 마법 공격력 0.
- 지팡이 · 홀: 지금 공격력 → 마법 공격력.
- 새 옵션: 모든 무기에 「마법 공격력 +」, 지팡이 · 홀에 「물리 공격력 +」.
- 「주문 피해 %」 옵션 폐지 → 기존 장비는 아이템 레벨에 맞는 마법 공격력으로 바꿔 준다. 「피해 %」는 공통으로 남긴다.

### 새 무기: 단검 (민첩 한손 근접)
- 빠른 공격 · 치명타 · 회피. 그림은 Flare 단검(남 · 여 · 바닥) 사용.
- 활은 양손 원거리 그대로.

### 보조 칸
| 아이템 | 효과 | 주 사용 |
|---|---|---|
| 방패 | 방어 · 막기 | 체력 |
| 보주 (있음) | MP · MP 회복 + 마법 공격력 조금 | 정신 (홀 + 보주) |
| 마도서 (새 일반 아이템) | 마법 공격력 높음 + 지능 옵션 | 마검사 · 혼합 마법 |
| 화살통 (전설) | 그대로 | 민첩 활 |

### 세팅 예
| 세팅 | 갈래 |
|---|---|
| 양손검 | 힘 |
| 활 | 민첩 원거리 |
| 지팡이 | 지능 |
| 홀 + 보주 | 정신 |
| 한손 무기 + 방패 | 체력 |
| 한손검 + 마도서 | 힘+지능 (마검사) |
| 한손 둔기 + 보주 | 힘+정신 · 체력+정신 (성기사) |
| 단검 + 마도서 / 보주 / 방패 | 민첩+지능 / 민첩+정신 / 민첩+체력 |
| 단검 · 활 | 힘+민첩은 검 + 단검 계열 스킬 |

## 3. 스킬 개편

- 단일 갈래마다 약 30~35개 (지금 지능 55 · 민첩 50 · 힘 47 · 체력 43 · 정신 43).
  - 지능: 원소별 같은 모양 반복 줄이기.
  - 민첩: 활 계열 + 단검 계열로 나눈다 (기교 스킬 연막 · 독 바르기 · 그림자 걸음 · 단검 부채가 단검 계열의 바탕).
- 같은 효과 버프는 아래 · 중간 · 최고 하나씩 (정신 보호막 셋, 치명타 넷, 피해 % · 광란).
- 빈 역할: 힘 = 받는 피해 감소, 민첩 = 뒤로 구르기, 지능 = 묶기, 정신 = 보호막 + 마력 딜.
- 혼합 스킬: 2스탯 10조합 × 6~8개 (각성 단계마다), 3스탯 10갈래 × 2개 (4 · 5차). 혼합 캐릭터는 단일 + 혼합을 섞어 쓴다.
- 없어지는 스킬을 배운 캐릭터는 같은 갈래 · 단계 스킬로 바꿔 주고 숙련도도 옮긴다.

## 4. 진행 순서

1. 피해 계산 + 공격력 분리 + 단검 · 마도서 · 새 옵션 · 주문 피해 % 변환 (한 번에).
2. 스킬 개편: 갈래별 남길 것 · 합칠 것 · 새로 만들 것 표를 먼저 확인받고 반영.
